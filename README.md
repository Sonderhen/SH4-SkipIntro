# SH4 Skip Intro

A mod for **Silent Hill 4: The Room (PC)** that lets you skip the start-up logos.

Works with the **GOG version (v7)**. Support for other versions is planned.

## What it does

During the start-up logos, press **Skip** (the button set in the game's controls). The game goes straight to the main menu and skips the remaining logos and the opening movie.

If you don't press it, the game starts as usual.

## Requirements

- [SH4 DLL Loader]([../SH4DLLLoader](https://github.com/Sonderhen/SH4-DLLLoader/releases))

## Installation

Copy `SH4SkipIntro.dll` to the game folder.

## Log

Messages go to `SH4CustomModules.log`, next to the game's exe.

## Building

Visual Studio, **Release | Win32**.
